# Cohub Account UI

English | [中文](README.zh.md)

Independently loadable DSH browser UI for Cohub device sign-in and logout. The browser receives only public account snapshots, verification codes, and verification links. Access tokens, refresh tokens, private device codes, persistence, and refresh remain owned by the Host-side Cohub Account package.

## Model Experience

None, as this browser-side account UI registers no prompt, tool, message, or provider request.

#### KV Cache effect

None.

## Known Limitations and Deferred Work

The UI does not list Spaces, models, generation capabilities, Boards, Works, shells, or local Workspaces.
