# DSH Cohub Board

English | [中文](README.zh.md)

An independently loadable, read-only Cohub Board browser for DSH. It adds its own sidebar action and overlay. Space files remain cloud folders and never become local Workspaces.

## Model experience

This package is a browser surface, not a model provider. It uses the separate Cohub Account, Space, and Board adapters.

## Limitations

The first version browses manifests and renders Board nodes and connections. It does not edit Boards, publish Works, control playback, run Cohub Sessions, or proxy private binary assets.
