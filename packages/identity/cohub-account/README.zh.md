# @deepseek-ai/dsh-cohub-account

[English](README.md) | 中文

Host 侧唯一 Cohub 账号会话所有者。它执行 Logto 设备授权，把完整私有会话保存到一个 DSH 凭证引用之后，对刷新操作做单航班合并，并在报告远端撤销失败前先清理本地状态。Cohub 适配器只能通过 `ctx.cohubAccount.getAccessToken()` 取得访问令牌；浏览器侧消费者只能看到不含令牌的快照和公开设备授权字段。

损坏的已存会话会令插件初始化明确失败，不会被自动清空或替换。刷新被服务端明确拒绝时，已存会话会被移除并要求重新登录。临时刷新失败会显示错误，同时保留已存会话供后续重试。令牌交换成功但账号资料读取失败时，已交换的私有会话只保留在内存中，重试不会再次使用一次性设备码。迟到的登录或刷新结果不能撤销登出。

本包使用平台 HTTP 接口实现协议，不依赖 Cohub CLI 或 SDK。本包自身源码与包元数据保持 MIT；下游分发仍需核算所组合 DSH 包的许可证。

## 模型体验

无，因为账号状态与凭证属于 Host 能力，不会注入模型可见上下文。

#### KV Cache 影响

无。

## 已知限制与后续工作

- 本包不包含账号界面或 API 映射。轮询调度属于后续界面或传输消费者；当前服务只提供一次明确轮询操作和服务端指定的重试间隔。
